# WCA Data Analysis and Prediction

A menu-driven Python application for analyzing World Cube Association (WCA) competition data and extracting insights from competitor, country, event, and global performance data.

## Features

### Competitor Analysis

* Analyze competitors using their WCA ID
* Analyze performance across different events
* Calculate best and average solve times
* Analyze performance improvement over time
* Predict future solve times using Linear Regression
* Estimate podium probability based on historical performance and trends
* Generate competitor performance visualizations

### Country Analysis

* Analyze competition performance by country
* Compare country-level performance statistics
* Examine participation and performance trends

### Event Analysis

* Analyze performance across WCA events
* Compare best and average solve times
* Examine event-level performance trends
* Visualize event performance statistics

### Global Analysis

* Analyze overall WCA competition statistics
* Examine competitor and competition statistics
* Analyze performance trends across years
* Identify trends across different events

### Predictive Analysis

* Linear Regression for future solve-time prediction
* R²-based evaluation of the historical fit
* Historical and trend-based podium probability estimation

### Data Visualization

* Performance trend graphs
* Best vs. average solve-time comparisons
* Podium probability visualizations
* Event performance charts
* Statistical visualizations

The project uses official World Cube Association (WCA) export datasets containing information on:

* Competitors
* Competition results
* Rankings
* Events
* Countries
* Competitions
* Rounds
* Scrambles
* Result attempts
* Formats

## Project Objective

The objective of this project is to analyze large-scale WCA competition data and identify meaningful patterns in competitor, country, event, and global performance.

The project combines data preprocessing, exploratory data analysis, statistical analysis, data visualization, and machine learning-based prediction.

## Dataset

The datasets used in this project are obtained from the official World Cube Association (WCA) Results Database Export.

**Official WCA Data Source:**
https://www.worldcubeassociation.org/export/results

The WCA database contains competition, competitor, event, result, ranking, and related information used for the analysis and prediction tasks in this project.

> **Note:** The dataset files are not included in this GitHub repository due to their large file size. They can be downloaded directly from the official WCA Results Export page linked above.
